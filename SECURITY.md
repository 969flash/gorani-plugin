# Security

Please report security problems privately. Do not open a public issue.

- Email: gorani.3d@gmail.com
- Or use GitHub's private vulnerability reporting on this repository (Security tab).

Include the version, the host (Rhino, SketchUp, Blender, Archicad) and steps to reproduce. We reply as soon as we can.

Scope: the plugin code in this repository. Values that ship inside every installed copy (the Firebase web API key, the GA4 Measurement Protocol secret, data download addresses) are public by design and are not secrets.
