## 0. 요약

### 결론 한 줄
국내 플랫폼은 거의 전부 **"필지 → 규모검토/AI 가설계 → 사업성 리포트"**(부동산 개발 의사결정) 축에 서 있고, **도시설계용 컨텍스트 산출물(레이어 분리된 벡터 베이스맵, 속성 있는 3D 컨텍스트, 가로·지형·공공공간 현황도)을 파일로 주는 곳은 없다.** 유일하게 "파일을 주는" 축은 빌드잇 지적도 다운로드(DWG/DXF, 3만㎡ 이하 무료)와 공공 데이터 포털(SHP/DXF/IMG)이며, 전부 "원재료"다. (브이월드 3단계의 obj·dae·3ds 등 6종 형식은 보도자료상 "가지고 있는 3D 파일로 손쉽게 편집하고 지도에 적용", 즉 사용자 모델 업로드·편집 맥락이라 건물 모델 반출 근거가 아니다 — 반출 가능 여부는 **확인 필요**, §2.3.) 원재료를 도시설계 작업 단위(Rhino 레이어·AI 레이어·분석도)로 조립해 주는 것이 우리 툴의 자리다.

### UrbanDesignTool 추천 산출물(이 조사의 결론)
1. **3dm 컨텍스트**: 필지(속성 포함), 건물 매스(GIS건물통합정보 높이·층수·용도·연도 → 사용자 텍스트 속성), 지형 메시(DEM 5m; 서울은 오픈랩 DEM 1m 확인 시 승격) + 등고선, 도로 중심선·경계, 하천(지목 '하천·구거' 필지 + 수치지형도 수계). 레이어 체계 고정.
2. **일러스트 베이스맵(AI/SVG)**: 위 레이어를 도시설계 관행(건물 층수별 그레이 톤, 도로 위계별 선굵기, 필지선 세선, 하천 블루) 스타일로 내보내기. 기존 Seoungsu SVG 스크립트 재사용.
3. **현황 분석도 세트(PNG/SVG + 수치 표)**: 층수·용도·노후도·국공유지·용도지역·지구단위 구역·경사도·역세권 반경. 이 8종이 "국내 플랫폼이 화면으로만 주는 것"의 파일화다. 원천 확인 후 추가 후보: 인구·상권·역사문화·재해(§2.6).
4. 하지 말 것: 규모검토·AI 가설계·사업성 리포트. 이미 6개 플랫폼이 무료~7천원대에 제공(§1).

## 6. 결론

### 6.1 공통 산출물 TOP 10 → 우리 툴 대응
§0 표 참조. 요지: 1~6(필지정보·거래가·대장·규모검토·가설계·사업성)은 **포화 시장**이므로 만들지 않는다. 7~10(3D 뷰·시뮬레이션·지적 CAD·중첩 측정)은 "화면"이 기본이고 파일화된 것은 지적 CAD뿐이다. 우리는 7~10을 **Rhino 지오메트리 + AI 레이어**로 파일화한다.

### 6.2 아무도 안 주는 것 → 제품 정의
§0 표 참조. 가장 큰 공백 3개:
1. **속성 유지 3D 컨텍스트(3dm)** — 건물에 층수·용도·연도, 지형 메시, 도로·하천 객체. 공공 원천(GIS건물통합정보 SHP+CSV EPSG:5186, DEM IMG, 수치지형도 DXF/NGI)이 모두 무료로 있고, 브이월드 건물 모델 반출은 확인 필요이므로 보강 후보에서 보류; 보강 후보는 S-Map 오픈랩 3D 데이터 신청(§2.1)·Overture Maps buildings(§4.4).
2. **레이어 분리 베이스맵(AI/SVG)** — Cadmapper만 Illustrator를 지원하고 국내는 전무.
3. **필지 단위 현황 주제도 세트** — 노후도·층수·용도·국공유지·용도지역·지구단위 구역·경사·역세권. 부동산플래닛·S-Map·K-Geo가 화면으로 보여주는 것을 SVG/CSV로. 지구단위 구역은 브이월드 데이터마켓 SHP로 원천 확보(§2.3). 원천 확인 후 인구·상권·역사문화·재해 추가(§2.6).

### 6.3 참고할 UX
- 빌드잇 지적도 다운로드: "범위 그리기 → 파일 즉시"(무료 한도 30,000㎡). 우리는 "필지 선택 또는 반경/사각형 → 3dm+AI+분석도".
- S-Map 분석 메뉴 명명(일조권·가시권·경사도·스카이라인·버퍼)을 분석도 메뉴 이름으로 차용.
- LBDeveloper처럼 산출물을 "엑셀 조서 + PDF" 로 분리 — 우리는 "3dm + AI + CSV(필지·건물 조서)".
