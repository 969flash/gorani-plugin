## Gorani와 다른 점 — 사업 방식이 왜 다른가

MassLabs는 데이터를 서버에서 모아 계산해 주는 웹 서비스라 쓸 때마다 비용이 들고, 그래서 면적·월 횟수로 막고 돈을 받는다.
Gorani는 사용자 PC에서 계산하고 데이터는 정적 파일이라 쓸수록 드는 비용이 거의 없다 — 같은 한도를 따라 할 까닭이 없다(손님 생성 횟수 제한 없음, `docs/account_plan.md`).

## 따라 하지 않을 것

- 데이터 출처·기준일 미표기 — Gorani는 늘 적는다(공공누리·ODbL 의무이자 차별점). 1:5,000 등고선 국외 반출 규정도 지킨다.
- 일조·그림자·바람·열쾌적 분석 — 이 프로젝트의 목적이 아니다(CLAUDE.md '배치·법규·일조 로직은 목적이 아니다').
- 기간형 체험(14일)·월 사용 횟수 — 공모전 직전에 처음 쓰는 학생에게 맞지 않고, 우리는 쓸 때 비용이 들지 않는다.
- 연결 코드 — 우리는 브라우저 로그인 뒤 바로 돌아오는 방식으로 한 단계 줄였다.
- 국내 사용자에게 영어만 있는 약관, 약관 안 숫자 어긋남.

## 확인 안 됨

한국 데이터 원천(VWorld 등)과 정밀도, 지형 원천(DEM·등고선), 비로그인 범위·로그인 벽 위치, '월 사용 1회'의 단위, 가격 두 개의 뜻, 실제 사용자 수.
