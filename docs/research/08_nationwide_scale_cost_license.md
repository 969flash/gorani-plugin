### 0.3 라이선스 핵심 발견 5가지
1. **VWorld 이용약관(제13조·제19조)은 '영리 목적 이용'과 '데이터 무단 저장'을 운영기관 동의·사전 승낙 사항으로 둔다.** 반면 같은 사이트의 저작권정책은 **공공누리 제1유형**을 명시하며 "공공데이터: 영리 목적의 이용을 포함한 자유로운 활용이 보장"이라고 쓴다. → 데이터마켓 **벌크 파일(상세 페이지에 CC BY·공공누리 표기)**은 표기대로 쓰고, **API 응답은 저장·재배포하지 않는다**가 안전한 해석. 다만 제19조 원문은 "오픈플랫폼에서 제공되는 데이터"라고만 하여 **데이터마켓 벌크도 포함될 여지**가 있으므로, 서면 질의 결과 전까지 벌크의 번들 판정은 '가능(질의 중)'(§5.1·§5.6).
2. **공공데이터법 제3조④**: "공공기관은 다른 법률에 특별한 규정이 있는 경우 또는 제28조제1항 각 호의 경우를 제외하고는 공공데이터의 영리적 이용인 경우에도 이를 금지 또는 제한하여서는 아니 된다." 토지특성·토지이용계획의 VWorld '미지정' 표기는 결격이 아니라 **메타데이터 누락**이며, 공공데이터포털(제26조①의 법정 제공 창구) 표기 '제한 없음'을 따른다(§5.4).
3. **연속지적도형정보**는 VWorld CC BY / 공공데이터포털 제4유형(상업적 이용·변경 금지)으로 충돌. 포털 표기가 더 좁으므로 **번들·납품물 포함 금지**로 둔다. 이 프로젝트의 필지 폴리곤은 '토지특성공간정보'(dsId=4)에서 오지만, (a) dsId=4 설명문이 "토지특성과 연속지적도를 융복합하여 … 생성한 공간정보"라 **도형 자체가 연속지적도 파생물**이고 (b) 포털 15048121 '제한 없음'의 행수 161,814,505는 CSV 속성 건수와 같아 **SHP 도형에 대한 포털 표기는 직접 확인되지 않았다**. 따라서 '실무 영향 없음·번들 가능'은 국가공간정보센터 질의 결과 전까지 **추정**이다(§5.4).
4. **국토지리정보원 별표 1(원문 PDF 확인)**: 1:1,000 이상 등고선·표고점은 공개제한, 공개 지도라도 "인터넷·내비게이션·휴대폰 등을 통해 좌표와 1:5,000 축척 이상 지도의 등고선·표고값 표시 불가". 항공사진은 "해상도 25cm보다 정밀한 항공사진은 건물·토지의 소유자와 … 관리기관의 장이 승인한 경우에 한하여 제공 또는 판매"(§5.2·§5.5).
5. **공공누리 1유형 = CC BY 4.0과 실질 동일**(출처표시만, 상업·변경 허용). 차이는 출처표시 양식(공공누리는 기관명·연도·개방유형 문구, CC BY는 저작자·라이선스 링크·변경 표시)과 CC BY 4.0의 '하류 수령자 자동 허락'(2(a)(5)) 명문 여부(§5.3).

마이크로벤치 스크립트(재현용, `/usr/bin/python3` 3.9 · sqlite 3.51.0 · pyogrio 0.11.1 · shapely 2.0.7, in-memory DB):

```python
# /tmp/bench08.py — 08 §1 마이크로벤치
import sqlite3, time, json, random, glob, os, pyogrio
random.seed(0); N = 200_000
def poly_json(cx, cy, n=20):  # 꼭짓점 20개 → geometry_json 평균 538 B(서울 DB 평균 456 B와 유사)
    pts = [[round(cx + random.uniform(-30, 30), 2), round(cy + random.uniform(-30, 30), 2)] for _ in range(n)]
    pts.append(pts[0]); return json.dumps({"type": "Polygon", "coordinates": [pts]})
rows = []
for i in range(N):
    cx, cy = 190000 + random.random() * 40000, 540000 + random.random() * 30000
    rows.append((f"11{i:017d}", "대", round(random.uniform(50, 2000), 1), "제2종일반주거지역", "20260520", cx, cy, poly_json(cx, cy)))
con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE parcels(pnu TEXT PRIMARY KEY, land_category TEXT, area REAL, use_zone TEXT, base_date TEXT, cx REAL, cy REAL, geometry_json TEXT)")
t = time.perf_counter(); con.executemany("INSERT INTO parcels VALUES(?,?,?,?,?,?,?,?)", rows); con.commit(); print("INSERT", time.perf_counter() - t)
con.execute("CREATE VIRTUAL TABLE parcels_rtree USING rtree(id, minx, maxx, miny, maxy)")
bb = [(i, r[5] - 30, r[5] + 30, r[6] - 30, r[6] + 30) for i, r in enumerate(rows)]
t = time.perf_counter(); con.executemany("INSERT INTO parcels_rtree VALUES(?,?,?,?,?)", bb); con.commit(); print("R-tree", time.perf_counter() - t)
files = sorted(glob.glob(os.path.expanduser("~/Documents/GitHub/Seoungsu/data/raw/shp/37705083/*.shp")))  # 42 파일
big = [f for f in files if os.path.basename(f) in ("N3A_B0010000.shp", "N3L_A0020000.shp", "N3A_A0010000.shp")]  # 건물·도로중심선·도로경계면
for label, sel in (("전체 42", files), ("대형 3", big)):
    pyogrio.read_dataframe(sel[0])  # warm-up
    t = time.perf_counter(); n = sum(len(pyogrio.read_dataframe(f)) for f in sel); el = time.perf_counter() - t
    print(label, n, "feat", round(el, 2), "s", round(n / el / 1000, 1), "k feat/s")
```

### 5.5 정사영상·항공사진의 인쇄물·공모 도판 사용

## 7. 결론

### 7.1 추천안과 근거
- **(ii)+(iii) 혼합**(§0.1). 결정적 근거 4가지: ① 전국 SQLite 74~91 GB는 배포 불가, 시도 패키지는 가능(§2.4) ② VWorld 2D API가 군 단위까지 전국을 덮는 것을 실측(§3.1, BOX 좌표 기록) ③ 지형은 API가 없어 벌크 수령이 불가피(§4.1 D; 광역분만 공개DEM·GLO-30 대체) ④ 이용약관 제19조 때문에 API 응답으로 DB를 만들 수 없고, 벌크는 CC BY·1유형·'제한 없음'이라 번들 가능(§5.1·§5.4 — 단 dsId=4 도형은 '추정', VWorld 벌크 전반은 제19조 범위 '질의 중').
- 1인 개발·macOS 제약은 **"수령은 Windows VM 연 1회, 빌드는 macOS"**로 흡수. 플러그인은 ① 번들 서울 패키지 ② 패키지 빌더(사용자 zip → SQLite) ③ 런타임 API 세 층으로 만든다.
- 상업 배포 전 **서면 질의 3건**: VWorld(약관 제13·19조와 저작권정책·CC BY 표기의 관계 — 특히 제19조가 데이터마켓 벌크에 미치는지, 유료 플러그인에서의 API 사용·결과 파일 납품), 국토지리정보원(1:5,000 등고선·표고값의 데스크톱 처리·파일 납품이 '인터넷 등을 통한 표시'인지), 국가공간정보센터(연속지적도형정보 CC BY vs 제4유형, 토지특성공간정보 SHP 도형의 파생 관계·이용허락 범위).
