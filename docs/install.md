# 설치 — 새 PC에서 한 번만

Rhino 8 전용. 개발용 python·pip 패키지·인터넷이 필요 없다(Rhino 내장 CPython + 표준 라이브러리만 쓴다).

## 1. 폴더 복사

`UrbanDesignTool` 폴더를 통째로 내 PC 하드디스크로 복사한다. 예) `C:\UrbanDesignTool` 또는 `~/UrbanDesignTool`.
USB에서 바로 쓰지 않는다 — DB 3.6 GB를 읽는 속도가 느리다.

## 2. 데이터 파일 확인

| 파일 | 내용 | 없으면 |
|---|---|---|
| `data/seoul_site.db` (≈2.1 GB) | 서울 필지 898,800건 — 필수 | 패널이 "준비 안 됨" 블로커를 띄운다 |
| `data/seoul_context.db` (≈1.5 GB) | 서울 건물·도로·지형·수계(도엽 139장) — 권장 | 필지·대상지만 생성되고 시트 7~10·12·13이 빈다 |
| `.env` | `VWORLD_API_KEY=…`(건물 최신화·주소 보조검색), `DATA_GO_KR_KEY=…`(건축HUB 철거·말소, 선택) | 없어도 동작. 패널 [.env 열기]가 두 줄 템플릿을 만든다. `=` 뒤에 공백을 두지 말 것 |

배포판을 받았다면 세 파일이 이미 들어 있다. 직접 만들려면 `docs/data_sources.md` §0.

## 3. 최초 1회 설치

Rhino 8을 켜고 명령창에 `ScriptEditor`를 입력한다. 스크립트 에디터에서 아래 파일을 열고 실행(▶)한다.

    <복사한 폴더>/scripts/cmd_install.py

"명령 등록 완료" 창이 뜨면 끝. 폴더를 다른 경로로 옮겼을 때만 다시 실행한다.

## 4. 사용

Rhino 명령창에 `UrbanSite` 또는 `대지검토`를 입력하면 패널이 열린다. 툴바 버튼을 쓰려면 한 번만 `ToolBar` 명령(맥: 창 > 도구모음…)에서 '대지검토'를 켠다.

- 결과는 `result/<날짜>/<대상지>/`에 쌓인다(`context.3dm`, `basemap_<축척>.ai`, `sheets/*.svg`, `tables/*.csv`, `log.txt`).
- 문서 단위는 mm·cm·m 아무거나 된다. 내부 계산은 m이고 베이크 때 문서 단위로 환산한다. 문서에 원점(`UDT_ORIGIN_E/N`)이 기록되어 같은 문서에 대상지를 여러 개 넣어도 좌표계가 하나다.
- 등고선·표고값·3D 컨텍스트는 온라인에 올리지 않는다(국토지리정보원 보안관리규정 별표1). 파일 납품만.

## 5. 문제가 생기면

- 패널이 안 열림: `scripts/cmd_install.py`를 다시 실행 → 명령창의 오류 메시지를 복사해 개발자에게.
- "준비 안 됨": `data/seoul_site.db` 경로 확인.
- .ai를 열 때 '레거시 텍스트 업데이트'를 묻는다: 라벨이 레거시 텍스트라서다. 업데이트하지 않아도 한글은 보인다. 글꼴이 없으면 대체 글꼴로 바뀐다.
- 패널 로그: 결과 폴더 `log.txt`, 브리지 진단 `임시폴더/urban_design_tool_panel_debug.log`.
