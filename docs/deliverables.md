- 우선순위: **P0** = 첫 릴리스에 반드시 / **P1** = 데이터가 있으면 / **P2** = 선택·후속.

### A.2 범위(반경) 옵션

| 옵션 | 값 | 용도 | 근거 |
|---|---|---|---|
| 반경 | **500 m(기본)** / 300 m / 1,000 m / 사용자 입력 | 서울시 실태조사·지구단위 종합분석도의 "구역 주변 500 m" 원칙. 1 km 이상이면 파일 분할 권장 | 03 §4.4·§5, 07 §8 |
| 형태 | 대상지 경계 버퍼(기본) / 중심 원 / 사각형(도엽 단위) | 사각형은 베이스맵 프레임과 맞출 때 | 06 §3 |
| 클리핑 | 입력 점·선·면을 메시 **생성 전에** shapely로 자른다(범위 경계 폴리곤을 TIN에 포함) | 외곽 긴 삼각형 방지 | 07 §1.4 |

규모 감: 1 km²당 건물 약 1,700동·TIN 약 5천 점 [07 §1.3·§8]. 반경 500 m(≈0.8 km²)면 건물 1~2천 동, 1 km면 5~6천 동 — rhino3dm 쓰기 수 초, 파일 수 MB~수십 MB.

### A.3 원점·단위·좌표 규칙

| 항목 | 규칙 | 근거 |
|---|---|---|
| 단위 | m, 절대 허용오차 0.001. 파일에 `ModelUnitSystem=Meters` 기록 → mm 문서에 Import하면 Rhino가 자동 환산(00 실측) | 00 §1, 07 §6.1 |

### A.4 건물 높이 규칙 (08 실측 기반 개정 — 종전 `3.2 × 층수` 규칙 폐기)

**바꾼 이유** [08높이 §0·§1]: 성수 겹침 영역(2.38 km², VW 6,840동 vs 수치지형도 5,411동) 실측에서 ① `grnd_flr`는 아파트에서 **48.8 %만 일치**(21층+ 중앙값 −12층; 불일치의 72 %는 부속건물 대장이 탑동 폴리곤에 붙은 것 — `archarea < 발자국×0.5`) ② 층고는 층수대에 따라 1–2층 3.80 → 21층+ 2.73 m로 변해 **절편이 있는 모델**이 맞고(`3.2n` MAE 1.54 m → 용도별 `a+b·n` 1.21 m, 공동주택 2.62 → 1.35 m) ③ `height`(채움 30 %)는 「건축물대장의 기재 및 관리 등에 관한 규칙」 별표 '너. 높이 — 영 제119조제1항제5호에 따라 산정'이라 **법정 높이**(옥탑 1/8 이하 불산입)로 신뢰 가능 ④ 1990년 이전 건물은 `height` 채움 8~14 %라 노후 주거지에서는 층수 모델이 사실상 전부. 수치는 성수·동대문 띠의 값이라 강남·구도심 재실측 전까지 상수는 잠정.

### B.4 법적 주의 — 등고선·표고값

국토지리정보원 보안관리규정 별표 1: 공개 지도라도 "인터넷 등을 통해 1:5,000 축척 이상 지도의 등고선·표고값 표시 불가" [05 §4.3]. 데스크톱 처리·파일 납품은 해당하지 않는다는 해석이 필요하고 데이터마켓 CC BY 배포와의 양립은 **확인 필요**. → `09_contour`·`09b_spot`과 3dm `CTX::Terrain`은 **웹 공유·클라우드 렌더 기능에서 제외**가 기본값. 1:1000 등고선은 공개제한이라 배포본에 넣지 않는다.

## F. 배포 구성 — 서울 번들 + 시도 패키지 + 런타임 API (08 전국 확장 조사 반영)

| 층 | 내용 | 근거 |
|---|---|---|
| ① 번들(배포본 DB) | 서울 필지 DB(2.0 GB, 보유) + 서울 컨텍스트 DB(1:5000 139도엽 또는 연속수치지형도 서울분). 라이선스 '제한 없음·공공누리 1유형·CC BY' 벌크만. 전국 필지 DB는 SQLite ≈ 74~91 GB라 배포 불가 | 08전국 §0.1·§2.4 |
| ② 시도 패키지 빌더 | 사용자가 VWorld 데이터마켓에서 받은 zip(연속지적·토지이용계획·GIS건물·토지특성 시군구 SHP)을 지정하면 **로컬에서 SQLite 생성**(시도 0.5~14 GB). 500 MB 초과 파일은 라온K(Windows 전용) → UTM(무료)+Windows 11 Pro(₩324,600) VM 1회 경로 문서화. 시도 경계 대상지는 DB `ATTACH`로 2개 패키지 동시 로드 | 08전국 §3.4·§4.1·§4.3 |
| ③ 런타임 API | 대상지 반경 500 m는 VWorld 2D API 호출 ≈10~15회(건물·도로중심선·도시계획도로·용도지역·지구단위·하천·필지경계)로 최신화 — 군 단위까지 전국 커버(8지역 실측). 사용자 본인 키, 세션 캐시만. 지형은 API 없음 → 벌크(①②) 필수, 광역 산세만 공개DEM·GLO-30 래스터 | 08전국 §3.1·§4.2 |

로드맵: 1단계 서울(지금, macOS 단독 가능) → 2단계 수도권(경기 토지이용계획 CSV 875 MB 등 → Windows VM 1회) → 3단계 전국(연속수치지형도 20.7 GB). 상업 배포 전 서면 질의 3건(VWorld 약관 제13·19조, NGII 별표 1, 국가공간정보센터 연속지적 vs 토지특성 도형) [08전국 §7.1].
