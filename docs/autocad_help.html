Gorani for AutoCAD

Gorani draws the existing conditions around your site as a 2D CAD drawing: parcels and lot numbers, building outlines with floor counts, road edges and widths, contours, zoning boundaries. It is free.

Use

  1. Click Plug-ins > Gorani on the ribbon, or type GORANI in the command line. A small Gorani window opens.
  2. Pick parcels on the map, draw an area, or drop a point. Set the drawing unit (mm or m) and the text scale.
  3. Click Create CAD drawing. On Windows the drawing is inserted into the current drawing at 0,0 as a block. On Mac, type GORANI again to insert it.
  4. EXPLODE the block to get lines on their own US-* layers. The DXF file also stays in the Gorani/result folder in your user folder.

Data

Korea uses public data (cadastral map, building register, 1:5,000 digital topographic map, urban planning data). The first time you use an area, Gorani downloads that area's data pack. Outside Korea it uses OpenStreetMap. Parcel lines are not survey results: confirm legal boundaries and road widths with a survey before design.

Privacy

Gorani asks before sending anonymous usage statistics. See 969flash.github.io/gorani.

Uninstall

Remove Gorani in the Autodesk App Manager, or delete the Gorani.bundle folder from ApplicationPlugins. Your results in the Gorani folder are kept.

Gorani — 한국어

  1. 리본의 플러그인 > Gorani를 누르거나 명령줄에 GORANI를 입력합니다. 작은 Gorani 창이 뜹니다.
  2. 지도에서 필지를 고르거나 구역을 그리거나 위치를 찍습니다. 도면 단위(mm·m)와 글자 축척을 정합니다.
  3. CAD 도면 만들기를 누릅니다. Windows는 지금 도면 0,0에 블록으로 들어갑니다. 맥은 GORANI를 한 번 더 입력하면 들어갑니다.
  4. 블록을 분해(EXPLODE)하면 US-* 레이어별 선이 됩니다. DXF 파일은 사용자 폴더의 Gorani/result에도 남습니다.
