# 크롬 Claude용 브이월드 다운로드 프롬프트

사람이 먼저 vworld.kr에 로그인해 둔 뒤, 아래 블록을 그대로 크롬 Claude에 붙여 넣는다.
끝나면 `~/Downloads`에 쌓인 파일을 `data/raw/수치지형도_5000/`·`data/raw/vworld_GIS건물통합정보/`로 옮긴다(옮기는 스크립트는 개발 세션에서 처리).

너는 브이월드(https://www.vworld.kr) 사이트에서 공공 공간정보 파일을 내려받는 작업만 한다.
나는 이미 이 크롬에서 브이월드에 로그인해 두었다. 아래 규칙을 지키면서 두 가지 작업을 순서대로 끝내라.

[절대 규칙 — 로그인 세션 유지]
1. 탭 하나만 쓴다. 새 창·새 탭·시크릿 창을 열지 않는다. 브이월드 밖 사이트로 나가지 않는다.
2. "로그아웃", "회원정보", "비밀번호", "탈퇴" 메뉴·버튼은 어떤 경우에도 클릭하지 않는다.
3. "세션 연장", "로그인 연장", "계속 이용", "연장" 같은 팝업이 뜨면 즉시 연장 버튼을 누른다. "만료"·"종료"·"확인(로그아웃)" 쪽은 누르지 않는다.
4. 로그인 입력 화면이 나오거나 상단에 "로그인" 버튼이 보이면(=로그아웃된 상태) 아이디·비밀번호를 절대 입력하지 말고, 그 자리에서 멈춰 "로그인이 풀렸습니다. 다시 로그인해 주세요"라고 나에게 보고한다. 내가 로그인했다고 하면 하던 항목부터 다시 시작한다.
5. 다운로드 10건마다 화면 상단에서 로그인 상태(사용자 이름 또는 "로그아웃" 버튼이 보이는지)를 확인하고 결과를 한 줄로 보고한다.
6. 작업 사이에 쉬지 않는다. 5분 넘게 아무 조작 없이 두지 않는다. 뒤로가기 대신 메뉴로 이동한다. 새로고침은 꼭 필요할 때만 한다.
7. 다운로드는 한 번에 하나씩. 다운로드가 완료 표시될 때까지 기다린 뒤 다음으로 넘어간다. 파일 이름은 바꾸지 않는다. 저장 위치는 크롬 기본(다운로드 폴더) 그대로 둔다.
8. 플러그인·프로그램 설치(예: Raon-K 다운로드 솔루션)를 요구하는 창이 뜨고 설치 없이는 다운로드가 안 되면 설치하지 말고 멈춰서 나에게 알린다.
9. 사이트가 횟수 제한·용량 제한·오류를 보이면 같은 항목을 2번까지만 재시도하고, 그래도 안 되면 건너뛰고 "실패 목록"에 적는다.

[작업 A — 수치지형도 1:5000 ver 2.0 (SHP) 도엽 139장]
경로: 상단 메뉴 "지도" 또는 "지도조회" → "WebGL 지도보기" → 지도 화면 왼쪽 패널에서 "수치지형도"(또는 "다운로드 > 수치지형도") 메뉴를 연다.
검색 조건: 축척 1:5000, 버전 2.0만 체크(ver 1.0 dxf는 받지 않는다). 검색 방식은 "도엽번호"로 한다.
