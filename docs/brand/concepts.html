이번에 바꾼 것
  • 블루를 빼고 검정·흰 면 둘로만 그렸다(샘플과 같은 고대비)

  • 눈을 크게, 흰 하이라이트 한 점으로 살렸다
뿔에 대해 — 먼저 짚을 점
  • 고라니는 암수 모두 뿔이 없다. 사슴과 중 드문 경우라 이게 고라니의 정체성이다
  • 뿔 자리에서 강조할 것은 수컷의 엄니(위턱에서 내려온 송곳니) — '뱀파이어 사슴'으로 불리는 특징
  • 뿔을 달면 노루·사슴으로 읽힌다 → 아래 '뿔 비교'에서 직접 보세요
보는 법
  • 16·24·32·64·256은 화면 CSS px
  • '1× 실제 픽셀'은 Windows 100 % 배율 도구 막대에서 보이는 그대로를 4배 확대
  • 얼굴 배지는 24 px 이하에서 작은 크기판으로 바뀐다(안쪽 귀·하이라이트를 뺀다)

R옆모습 달리기 8장

엉덩이가 어깨보다 높은 고라니 체형(뒷다리가 길다), 큰 귀, 뿔 없음. 네 다리를 모은 장과 쭉 뻗은 장을 오가는 도약 달리기를 8장으로 돈다. 메뉴 막대의 달리는 고양이처럼 같은 실루엣이 16 px에서도 움직임으로 읽히게 했다.

결과 화면의 생성 진행 막대 위 — 고라니가 진행률만큼 달려간다
주의
생성은 Rhino UI 스레드에서 동기로 돈다. 진행 콜백 사이에는 화면이 멈출 수 있어 고라니가 제자리에서 멈춘 듯 보일 수 있다 → 위치는 진행률(fraction)에 묶고, 다리 장은 진행 푸시마다 한 장씩 넘기는 것을 기본으로 한다(아래 모의는 브라우저라 일정 속도로 돈다)
