## 1. 요약 — 설계 원칙

1. **한 화면에 결정 하나.** ① 어디(대상지) → ② 얼마나(범위·옵션) → ③ 기다림(생성) → ④ 무엇이 나왔나(결과). 네 단계가 전부이고 더 쪼개지 않는다.
2. **기본값으로 끝까지 간다.** 대상지만 고르면 ②는 "반경 500 m · 경계 버퍼 · A1 1:3000 · 시트 13장" 요약 카드 하나와 [생성] 버튼뿐. 나머지는 "고급" 아래에 접는다.
3. **경고는 생성 전에 보여주고(사전 점검), 생성 후에 다시 센다(결과).** 기준일·API 키·데이터 커버리지는 ②에서, 높이 추정 비중·정합 오차·건너뛴 피처는 ④에서. 어느 경고도 생성을 막지 않는다(빨간 경고 포함, deliverables §C 공통 ⑤).
4. **단계 수 = 상태 수.** JS 상태는 `step` 하나와 네 개의 데이터 덩어리(`lots`·`options`·`preflight`·`result`)뿐. 모달·중첩 패널 없음, 전역 오버레이는 "DB 없음" 블로커와 토스트 두 개만.
5. **되돌아갈 수 있고, 되돌아가도 잃지 않는다.** ④→②(옵션만 바꿔 재생성), ④→①(새 대상지)이 한 번의 클릭. 옵션은 Python이 `prefs.json`에 기억해 다음 실행에 그대로 복원한다.

## 3. 정보구조(IA)와 화면 흐름

### 3.1 IA

```
대지검토 (창 1개, 480×900)
├─ 헤더: 제목 · 스텝퍼 [① 대상지] [② 범위·옵션] [③ 생성] [④ 결과]
├─ 본문: 활성 단계 1개만 렌더 (section[data-step])
│   ① 대상지   : 검색줄 · 지도(남는 세로 전부) · 대상 필지 칩 목록 · 합계
│   ② 범위·옵션: 대상지 요약 1줄 · 기본 설정 카드 · 자료 상태(사전 점검) · [고급 ▸]
│   ③ 생성     : 단계별 진행률 · 현재 작업 1줄 · 로그 서랍 · [취소]
│   ④ 결과     : 요약 카드 · 경고 목록 · 동작 버튼 4개 · 시트 미리보기 · 산출물 목록
├─ 푸터: [← 뒤로]  [다음 → / 생성 / 새 대상지]  (단계별 1차 동작 1개)
└─ 전역: 토스트(오류·완료 4초) · "DB 없음" 블로커(본문 전체 덮음)
```

### 3.2 상태 전이

JS 상태 `step ∈ {1,2,3,4}` + `blocked`(DB 없음) 하나.

```
          init_state.db.lot_db == "missing"
   시작 ───────────────────────────────────▶ [블로커] ──(DB 준비 후 '다시 확인')──▶ ①
    │
    └─ 정상 ──▶ ① 대상지 ──(lots ≥ 1, 다음)──▶ ② 범위·옵션 ──(생성)──▶ ③ 생성 ──(done)──▶ ④ 결과
                 ▲    ▲                      │   ▲                     │                 │
                 │    │                      │   │   (error / 취소)     │                 │
                 │    └──────── 뒤로 ─────────┘   └─────────────────────┘ ③는 실패 시      │
                 │                                                       그 자리에 머물고  │
                 │                                   ④ "옵션 바꿔 다시" ─────────────────┘
                 └────────────────────────────────── ④ "새 대상지" ───────────────────────┘
```

규칙
- 스텝퍼의 완료된 단계(체크 표시)는 클릭으로 돌아갈 수 있다. 미완료 단계는 비활성(건너뛰기 금지). ③는 클릭 대상이 아니다(생성은 버튼으로만).
- ①에서 대상지가 0개면 [다음] 비활성 + 힌트 "지도에서 필지를 누르세요".
- ②에 들어올 때마다 `preflight`를 보낸다(대상지·반경이 바뀌면 자료 상태가 달라짐). 응답 전에도 [생성]은 눌린다 — 사전 점검은 정보이지 게이트가 아니다.
- ③는 자동 진입·자동 이탈. 성공하면 ④로, 실패·취소면 ③에 머물며 [뒤로]·[다시 시도]만 남는다.
- ④→② 이동 시 대상지는 유지, `result`는 유지(다시 생성하면 덮어씀). ④→① 이동 시 `lots`·`result` 초기화, `options`는 유지.
- 창을 닫았다 다시 열면 ①부터. 단 `options`는 `prefs.json`에서 복원.

## 10. 접근성·키보드

- 스텝퍼는 `<ol>` + `<button>`(완료 단계만 활성). 현재 단계 `aria-current="step"`. 단계 전환 시 본문 제목(`h2[tabindex=-1]`)으로 포커스 이동 → 스크린리더가 "2단계 범위·옵션"을 읽는다.
- 전역 단축키: `Enter` = 현재 단계 1차 동작(①에서 검색줄 포커스면 검색, 그 외 [다음]/[생성]). `Esc` = 드롭다운·디스클로저 닫기, 없으면 [뒤로]. `⌘/Ctrl+Enter` = 어디서든 1차 동작. `Alt+←/→` = 뒤로/다음.
- ① 지도: 키보드만으로 필지 선택은 지원하지 않는다(대신 검색 → 후보 목록을 ↑↓/Enter로 고르면 같은 결과). 후보 드롭다운은 `role=listbox`, 칩 목록의 ✕는 `aria-label="277-17 제외"`.
- ② 세그먼트는 `role=radiogroup`(←→ 이동), 체크는 네이티브 `<input type=checkbox>`, 고급은 네이티브 `<details>`.
- ③ 진행률 `role=progressbar aria-valuenow`, 현재 작업 1줄은 `aria-live="polite"`, 오류 카드는 `role=alert`. 로그는 live 아님(소음).
- ④ 경고 목록 `aria-live="polite"`로 1회 요약("경고 3건"). 미리보기 이미지 `alt`에 시트 이름.
- 색만으로 상태를 전하지 않는다(●/○/✓/✗/⚠ + 글자). 대비: 본문 4.5:1 이상, 보조 글자 4.6:1, 비활성은 3:1 이상(읽혀야 하는 비활성 텍스트는 muted 대신 sub).
- 글꼴 확대: 창 리사이즈·브라우저 확대(⌘+)에 레이아웃이 깨지지 않도록 고정 높이는 지도·썸네일에만.
- 동작 축소(`prefers-reduced-motion`)와 무관하게 애니메이션은 진행 막대 width 전환(150 ms)뿐.

### 11.1 바닐라 JS 구조 (파일 1개, 대략 1,200줄)

```js
const state = { step: 1, blocked: false,
  lots: [], lotState: null,        // lot_state 그대로
  options: {},                     // init_state.options → 사용자 변경
  preflight: null, progress: null, result: null,
  previews: {} };                  // sheet_id → data_url 캐시

function go(step) { state.step = step; render(); }
function render() {                // 단계 섹션 4개 중 하나만 표시, 나머지 hidden
  document.querySelectorAll("section[data-step]").forEach(s => s.hidden = +s.dataset.step !== state.step);
  renderStepper(); renderFooter();
  ({1: renderLots, 2: renderOptions, 3: renderProgress, 4: renderResult})[state.step]();
  if (state.step === 1) map.invalidateSize();   // hidden 상태에서 Leaflet 크기 0 문제
  document.querySelector(`section[data-step="${state.step}"] h2`).focus();

window.app = { receive(msg) { handlers[msg.type]?.(msg); } };
```
- 렌더는 `innerHTML` 템플릿 리터럴로 통째로 다시 그린다(입력 중인 필드만 예외: 검색줄·직접 반경 입력은 값을 보존). 가상 DOM 없음.
- 푸터 버튼은 단계별 테이블 하나로: `{1:[null,"다음"],2:["뒤로","생성 시작"],3:[null,"취소"],4:["옵션 바꿔 다시","새 대상지"]}`.
- 옵션 변경 → `state.options` 갱신 → `save_prefs`(500 ms) + ②면 `preflight`(300 ms) 디바운스.
- 스텝퍼 클릭 가드: `canGo(step)` = step ≤ maxReached && step !== 3.

### 11.2 Leaflet

- 인스턴스 1개, ① 섹션 안에만. `preferCanvas: true`, `zoomControl` 우측 하단.
- 레이어 3개: `tiles`(VWorld, `tileerror` 3회면 OSM으로 `setUrl`), `lotsLayer`(뷰포트 필지, moveend마다 교체), `targetLayer`(대상지, `lot_state.target_geojson`). 클릭 핸들러는 `lotsLayer`에만.
- 줌 < 17이면 `lotsLayer.clearLayers()` + 힌트 칩. 5,000건 limit 잘림(`truncated`)도 칩.
- ②의 미니맵은 Leaflet이 아니라 `<svg viewBox>`: target_geojson 좌표를 bbox 정규화해 path 1개 + 범위 외곽(버퍼는 Python이 `lot_state`에 `buffer_outline`을 함께 줘도 되고, v1은 원·사각형만 JS가 그리고 버퍼는 "경계 버퍼"라는 글자만).

### 11.3 긴 작업·진행률

- 생성은 Rhino 밖 python3 서브프로세스(deliverables A.5). 컨트롤러 `cmd_site.py`가 `subprocess.Popen(stdout=PIPE)`로 띄우고, 자식은 진행 상황을 **stdout에 JSON 1줄씩**(`{"phase":…,"percent":…}` / `{"log":…}`) 쓴다. Eto `UITimer`(200 ms)가 non-blocking으로 줄을 읽어 그대로 `progress`·`log`로 푸시. 이 동안 WebView는 멈추지 않는다.
- 자식이 끝나면 `context.json`을 읽어 `done`을 조립. `import_after`면 그 직전에 `busy on` → `_-Import`(UI 스레드, 수 초 멈춤) → `imported` → `busy off`.
- 취소 = `proc.terminate()`. 부분 폴더는 두고 `log.txt` 끝에 "cancelled" 기록.
- `export_basemap`도 UI 스레드. `busy` 푸시 → `AsyncInvoke`로 작업 예약(busy가 먼저 그려지도록, 옛 호스트 규칙 유지).

### 11.4 성능·크기

- 시트 미리보기 SVG는 1~3 MB(건물 2천 동). base64 푸시 1장씩, 캐시. 썸네일은 같은 data URL을 210 px `<img>`로 축소 표시(별도 썸네일 생성 없음). 13장 전부 펼치면 30 MB 정도 — 펼칠 때만, 순차 요청.
- `map_lots` GeoJSON은 소수 7자리·최대 5,000건(기존 `review_map.get_parcels_in_bbox`). 줌 17 조건으로 실측 1~2천 건.
- 로그 400줄 상한, 초과분 앞에서 버림.
- `prefs.json`은 Python이 `data/` 옆이 아니라 사용자 홈(`~/.urbandesigntool/prefs.json`)에 둔다 — 저장소 폴더를 더럽히지 않고 WebView `localStorage`(file:// 임시 파일 출처라 보장 안 됨)에 의존하지 않는다.

### 11.5 기존 자산 재사용

- `review_map.py`(타일 설정·bbox 필지·GeoJSON) 그대로. `panel_host.py`의 브리지(`bridge:flush` + title 이벤트, `__flush`)도 그대로 — 바뀌는 건 명령·푸시 이름뿐.
- `lot_db.load_parcels_in_bounds`, `pnu_loader` 주소 해석 재사용.
- 새로 필요한 Python: `preflight`(data_sources·source_files 테이블 + 도엽 커버리지 + 키 존재), `generate` 서브프로세스 드라이버, Import/Export 베이커 함수 2개.
