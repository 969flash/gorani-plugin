# 「Gorani」 패널 UX/UI 스펙

- 2026-10-19 개편. 사용자 시험 피드백(대상지·범위·옵션·결과 4단계가 길고, 범위 형태가 방식마다 다르고, 옵션·자료 상태·신뢰도가 이해되지 않음)을 반영해 **2화면(지도 → 결과)**으로 다시 짰다. 옛 4단계 스펙은 git 기록에 있다.
- 구현 계약(명령·푸시·상태)은 `docs/panel_ui.md`가 원본이다. 이 문서는 화면·행동·문안을 정한다. 시각 토큰은 `DESIGN.md`.
- 제약: Eto WebView 1장(480×900, 리사이즈 가능, 도킹 불가) · 단일 HTML + 바닐라 JS · Leaflet·Pretendard 인라인 · 같은 HTML을 Blender(브라우저)·SketchUp(HtmlDialog)도 쓴다.

## 1. 원칙

1. **주목적은 3D 모델이다.** 대상지와 범위만 정하면 [3D 모델 만들기] 한 번으로 Rhino 문서에 들어간다. 2D 자료(베이스맵 .ai·다이어그램·조서 CSV)는 3D가 끝난 뒤 결과 화면에서 "추가로 만들까요?"로 묻는다.
2. **화면은 둘.** 지도 화면(어디를·얼마나) → 결과 화면(진행 → 완료 → 2D 추가). 스텝퍼는 없다.
3. **기본값으로 끝까지 간다.** 3D 설정은 접어 두고 요약 한 줄만 보인다. 바꾸고 싶은 사람만 펼친다.
4. **사용자가 할 수 있는 일만 보인다.** 자료 기준일·신뢰도·경고 목록·레이어 경로(`CTX::…`)는 패널에 없다. 출처·기준일은 3dm(`context.json`, 레이어 메모)과 도면 출처 줄에 남는다.
5. **범위는 어느 방식이든 같다.** 원(반경) 또는 사각형(한 변), 대상지 중심 기준.
6. **진행 표시는 하나.** 지역 데이터 받기도 같은 막대·같은 단계 목록 안에서 보인다.

## 2. 대상지 방식 — 대상지가 있는가

| 방식 | 묶음 | 대상지 | 3D에서 달라지는 것 | 2D에서 달라지는 것 |
|---|---|---|---|---|
| 필지 `lots` | 대상지 정하기 | 고른 필지(합필) | 대상지 경계 커브, 대상지 바닥면·평탄화 가능 | 대상지 빨강 표시, 필지 조서 |
| 구역 `area` | 대상지 정하기 | 그린 경계(안의 필지 = 면적 50 % 이상) | 위와 같음 | 위와 같음 |
| 위치 `point` | 대상지 없이 | 없음 — 찍은 점이 범위 중심 | 대상지 관련 설정 없음 | 대상지 표시 없음 |

방식 칸은 `[필지 | 구역] [위치]` — 앞 둘을 한 묶음으로 붙이고 위치를 떼어 놓아 "대상지 있음/없음"이 눈에 보이게 한다. 방식을 바꾸면 고른 대상지가 지워지므로 토스트에 [되돌리기]를 단다.

### 3.1 도구줄·안내

- 검색칸 자리표시: 필지 "주소·지번으로 필지 찾기", 구역 "주소·지명으로 지도 이동", 위치 "주소·지명으로 위치 찍기".
- 안내 칩(지도 가운데 위, 파란 테두리 흰 면, 대상지가 생기면 사라진다):
  - 필지: 배율 17 미만 "지도를 확대하면 필지가 보입니다", 17 이상 "지도에서 필지를 눌러 고르세요(여러 개 가능)"
  - 구역: 그리는 중 "지도를 눌러 꼭짓점 · 첫 점이나 더블클릭으로 닫기 · Esc 취소" + 꼭짓점 수
  - 위치: "지도를 눌러 위치를 찍으세요"
- **구역은 칸을 누르는 즉시 그리기 상태다.** 트레이에 [Rhino 커브 가져오기](보조)·[다시 그리기]·[옮기기]가 상황에 따라 보인다. 구역을 다 그리면 그리기 상태가 끝난다.

### 3.2 트레이

트레이 높이는 창 높이로만 정한다(clamp(200 px, 100vh − 480 px, 256 px), 2026-10-22 — 상한 256 px는 3D 설정을 접은 트레이 중 가장 긴 것이고, 남는 높이는 전부 지도가 쓴다). 지도와는 8 px 띄우고, 스크롤하면 위 끝을 흐린다. 대상지를 고르거나 펼쳐도 지도 크기가 바뀌지 않아 화면이 밀리지 않는다. 펼친 내용은 트레이 안에서 스크롤하고, 3D 설정·필지 정보를 펼치면 그 머리를 트레이 맨 위로 올린다. 대상지가 없을 때는 다음 할 일 한 줄, 필지 방식은 최근 대상지(4개)를 보인다.

| 줄 | 내용 | 보이는 때 |
|---|---|---|
| 대상지 | 필지: [지번 외 n ⌄] · 합계 ㎡ · [✕]. 이름을 누르면 필지 목록(✕)·필지 정보가 펼쳐진다(따로 있던 '필지 n개 정보' 줄을 합침, 2026-10-19) / 구역: 면적 · 안의 필지 n / 위치: 가장 가까운 지번 "일대" | 대상지가 있을 때 |
| 범위 | 형태 2칸(원·사각형) + 크기 4칸. **기본 사각형 한 변 500 m**, 방식을 바꿔도 마지막 범위 유지. 원 = 반경 250·500·1,000·직접(100~2000 m), 사각형 = 한 변 500·1,000·2,000·직접(200~4000 m). 내부 값은 `radius`(사각형은 한 변의 절반). 지도에 즉시 그리고, 라벨은 범위 윗변 바깥에 붙인다 | 대상지가 있을 때 |
| 3D 설정 | 요약 한 줄 + ▾. 펼침 내용 §3.3 | 대상지가 있을 때 |

- 형태를 바꿔도 `radius`는 그대로다(원 500 m ↔ 사각형 한 변 1,000 m).
- 1 km를 넘으면 범위 줄 아래 회색 한 줄 "범위가 크면 만드는 데 1분 넘게 걸릴 수 있습니다".

## 4. 결과 화면

### 4.1 진행(3D·2D 공통)

```
┌ 카드 ─────────────────────────────────────────┐
│ 3D 모델 만드는 중                        [취소] │
│ 성수동2가 277-17 외 1, 사각형 한 변 500 m      │
│ ██████████░░░░░░░░░░░░░                        │
│ 42 %                                      0:14 │
│ ✓ 지역 데이터 받기                      성동구 │
│ ● 건물과 지형 불러오기                         │
│ ○ 3D 모델 만들기                               │
│ ○ Rhino 파일에 넣기                            │
│ ───────────────────────────────────────────── │
│ Rhino 안에서 만들어 Rhino 화면이 잠깐씩 멈출 수 있습니다. │
└───────────────────────────────────────────────┘
▸ 로그 자세히 보기 (n줄)        ← 카드 밖, 줄이 생기면 보인다
```

- 3D·2D 같은 카드 꼴이다(2026-10-19 Rhino QA). [취소]는 카드 오른쪽 위, 3D 진행 중 푸터는 없다. 2D 진행 카드는 3D 완료 카드 아래 2D 카드 자리에 들어가고 대상지 줄이 없다.
- 맨 아래 안내 줄은 문서에 넣는 동안(`busy`) "문서에 넣는 중입니다. 끝날 때까지 취소할 수 없습니다."로 바뀌고 [취소]가 비활성이 된다.
- 막대·고라니는 전환 없이 값으로 바로 간다. Rhino가 바쁘면 화면이 드문드문 그려져 전환 시작점(0 %)에 멈춰 보였다. 경과 시간도 진행 푸시마다 고친다.

- 막대 하나. 생성 전에 지역 데이터를 받으면 그 구간이 막대 앞 20 %를 차지한다(받을 게 없으면 0 %).
- 3D 단계: 지역 데이터 받기 · 건물·지형 불러오기(`query`) · 3D 모델 만들기(`terrain`) · Rhino 파일에 넣기(`write_3dm`).
- 2D 단계: 지역 데이터 받기 · 데이터 불러오기(`query`) · 베이스맵 · 다이어그램 · 조서 CSV(끈 것은 줄이 없다).
- 지도 밖 받기 줄(`#dl`)은 생성 중에 쓰지 않는다 — 지도에서 시군구 팩을 받을 때만.
- 실패: 단계 ✗ + 오류 블록(제목 한 줄 · 상세 접힘 · [로그 복사] · [폴더 열기]) + 푸터 [← 지도로] [다시 시도]. 취소: "취소됨 — 만든 데까지 폴더에 남아 있습니다".

- 3D 블록(2026-10-19 QA)
  - 제목 · 어디에 들어갔나 · 대상지 · 숫자 칸 셋(건물·범위·레이어) · [파일 위치 열기] 하나.
  - '대상지 보기'는 두지 않는다. 생성이 끝나면 Rhino 화면이 이미 대상지로 맞춰진다.
  - '다시 불러오기'는 아래 안내 줄 링크다. 이 대상지의 3D를 지우고 결과 폴더의 3dm에서 불러온다.
  - 불러오지 못했으면 제목이 "3D 파일을 만들었습니다 — Rhino에는 불러오지 못했습니다"이고, [Rhino에 불러오기](주행동)·[파일 위치 열기]가 나온다.
- 선택칸은 한 모양(높이 32 칩, 고르면 파란 테두리)이다. [직접]도 같은 칩이고, 고르면 바로 옆에 입력칸이 나오며 커서가 들어간다(칩 안에 입력칸을 넣지 않는다). 옵션 묶음 사이에는 선을 긋지 않는다 — 간격과 파란 제목으로만 나눈다.
- 2D 카드: 타일 셋. 타일을 누르면 켜지고, 켠 타일 안에만 칩이 열린다. 인쇄 용어(용지·축척)는 베이스맵 '직접'에서만 보인다.
  - 베이스맵: [보고서 A3]·[판넬 A1]은 축척을 자동으로 맞춘다. 범위(한 변·지름 = 2 × radius)가 용지에 들어가는 가장 상세한 축척(1:1,000 → 1:3,000 → 1:5,000)을 쓰고, 다 넘치면 1:5,000이다. [직접]은 용지·축척(여럿)을 고른다. '더 그리기' 칩 = 기본 꺼진 레이어. DWG는 Rhino만.
  - 다이어그램: 묶음 칩 [전체]·[현황도]·[분석도]. 기본(베이스맵·항공사진)은 현황도·분석도 둘 다에 든다. 그려 넣을 틀(경관·조망, 이미지맵, 종합분석)은 묶음에 넣지 않고 '더 넣기' [그려 넣을 틀] 칩으로 따로 켠다(기본 끔, 2026-10-19). [직접]은 묶음별 목록·층수 구분·표고 단계를 펼친다.
  - 결과 격자에서 빈 도면은 끝으로 간다. 표제(프로젝트명)는 [내 스타일로 저장]에 들지 않고, 스타일을 바꿔도 그대로다.
  - 버튼은 켠 개수를 보여 준다("2D 만들기 · 2개"). 하나도 안 켰으면 비활성.
- [2D 만들기] → 카드 자리에 §4.1 진행 → 끝나면 카드가 결과로 바뀐다.
  - 파일 덩어리 하나(라벨 열 64 px, 줄 사이 괘선 없음): 베이스맵 .ai 목록(누르면 열기) · 다른 축척(안 만든 축척 칩, 받기 아이콘) · CAD .dwg(켰으면)
  - 다이어그램 칸 격자(썸네일 — 누르면 패널 보기 창에서 SVG를 본다: 제목 · [‹][›] · [✕], 그림을 누르면 확대, ←→·Esc. '잘 나왔는지 본다'는 자리라 Illustrator를 거치지 않는다, 2026-10-19), [모두 .ai로 저장]
  - [2D 자료 만들기]마다 결과 폴더 안 새 폴더 `2D_<스타일>_<HHMM>/`에 쓴다(2026-10-21). 스타일이나 고른 도면을 바꿔 다시 만들어도 앞 폴더는 그대로 남고, 카드는 이번 것만 보인다. 다시 쓴 SVG 옆에 .ai가 있으면 .ai도 새로 쓴다(폴더에서 연 .ai가 옛 것이던 문제).
  - 조서 CSV 링크
  - 그 아래 [다른 2D도 만들기]가 카드를 다시 연다.
- 다이어그램 스타일은 만들기 전에 정한다(2026-10-19 사용자 결정). 2D 카드 다이어그램 타일의 [편집] → 스타일 화면(하위 화면, 미리보기를 위에 고정) → [적용]하면 `options.style`이 되고, [2D 자료 만들기] 때 그 스타일로 쓴다. 미리볼 도면은 이번에 고른 다이어그램(틀 제외). [←]는 바꾸지 않고 돌아간다. 고친 스타일이면 타일의 선택칸 맨 위에 '선명 (수정됨)'처럼 보인다. 만든 뒤 다시 그리기(예전 [스타일]·[n장에 적용])는 없다.
- 신뢰도·경고 목록·산출물 목록은 없다.

### 4.3 푸터

| 상태 | 왼쪽 | 오른쪽 |
|---|---|---|
| 지도 | [결과로 돌아가기 →] (떠나온 결과가 있고 대상지·범위·3D 설정이 그때와 같을 때만), 아니면 이미 만든 대상지일 때 '이 대상지의 이전 3D를 새것으로 바꿉니다' | [3D 모델 만들기] (대상지 없거나 그리는 중이면 비활성). 이 패널에서 이미 만든 대상지면 [3D 모델 다시 만들기] — 결과 폴더는 새로(`_<HHMM>`), 이전 폴더는 남는다 |
| 3D 진행 | (푸터 없음. [취소]는 진행 카드 오른쪽 위) | |
| 3D 완료 | [← 지도로] (2D 진행 중 비활성) | — |
| 3D 실패·취소 | [← 지도로] | [다시 시도] |
| 스타일 | [되돌리기] | [내 스타일로 저장] · [적용] |

[← 지도로]는 대상지·옵션을 그대로 두고 지도로 간다. 결과는 버리지 않고 맡겨 둔다(2026-10-19): 지도에서 둘러보기만 하고 오거나, 바꿨다가 되돌리면 [결과로 돌아가기]로 2D 카드(만든 2D 포함)까지 그대로 돌아간다. 대상지·범위·3D 설정 중 하나라도 다르면 버튼이 숨는다(2D 옵션은 비교하지 않는다). [3D 모델 만들기]를 누르면 맡긴 결과를 버린다(같은 대상지의 이전 3D는 문서에서 바뀐다). 새 대상지는 지도에서 대상지를 지우고 고른다.

## 5. Korea / Global

- 헤더 토글은 없다. 대상지(또는 지도 중심) 위치로 정한다: 한국 안 = Korea(국가 DB), 밖 = Global(OSM). 한국 밖으로 가면 필지 칸이 비활성이 되고 토스트 한 번.
- 한국 안에서도 OSM으로 만들고 싶은 사람은 더보기 메뉴 설정의 "한국에서도 OpenStreetMap 쓰기"(`options.region = "global"`).
- 첫 실행 판정(`region = null`)은 지금처럼 시간대·언어·국내 DB.

## 6. 더보기 메뉴

헤더 로고(Gorani)를 누르면 지도로 간다([← 지도로]와 같다, 만드는 중에는 안 감). 최근 대상지 · 설정(폴더 경로 [열기], 한국 자료 회색 토글 [국가 DB][OSM], 결과 언어 [한국어][English](폴더·파일 이름, 첫 값은 시스템 언어 — panel_ui.md '결과물 언어'), 사용 통계 — Blender·SketchUp만) · 도움(고라니 웹페이지 — `open_url{key:"website"}`) · 버전.
뺀 것(2026-10-19): VWorld 키(.env, 개발자용 — `docs/install.md`), 다시 확인(팩을 저절로 받는다), 로컬 install.md, 자료 기준일 표.
나중에 넣을 것: 받은 지역 데이터(목록·용량·지우기), 최근 대상지에 구역·위치 방식.

## 7. 문구 원칙

- 기술 용어 대신 결과로 말한다: "TIN·면 분류·정합 측정" → "3D 모델 만들기", "베이크" → "문서에 넣기", "현황도 시트" → "다이어그램".
- 화면에 레이어 경로·파일 형식 설명 문장을 쓰지 않는다. 필요하면 `title` 툴팁.
- "다이어그램"은 실무 보고서의 현황도·분석도다. 처음 나오는 자리(2D 카드)에 "현황도·분석도"를 함께 적는다.
